# Robotic Gripper

## Overview

This project focuses on the design and development of a two-finger
mechanical robotic gripper using Autodesk Fusion 360.

The gripper is designed to perform essential manipulation tasks such
as gripping, lifting, and releasing objects with precision and
efficiency. The design emphasizes functionality, ease of integration
with robotic systems, lightweight construction, and suitable material
selection.

## Objectives

- Design a functional robotic gripper using CAD modelling in Fusion 360.
- Enable gripping, lifting, and releasing of objects.
- Facilitate integration with robotic arms and automation systems.
- Select lightweight and durable materials suitable for fabrication.
- Validate the gripper mechanism through simulation.

## Design and Mechanism

The gripper consists of two mechanical fingers operated through a
gear-driven linkage mechanism.

The CAD design incorporates:

- Configured joints
- Gear mechanisms
- Gripper fingers
- Connecting links
- Mounting features
- Actuator placement
- Gripping range

The mounting arrangement allows the gripper to be integrated with
robotic arms or servo-based systems.

## Technical Specifications

| Parameter | Specification |
|---|---|
| Gripper Type | Two-finger mechanical |
| Actuation | Single SG90 Servo Motor |
| Mechanism | Gear-driven linkage |
| Materials | ABS, PLA, Aluminum |
| Fabrication | 3D printing and CNC machining |
| Simulation | Fusion 360 Motion Studies |

## Design and Manufacturing Workflow

The project follows a Computer Integrated Manufacturing (CIM)
workflow:

1. CAD modelling
2. CAM toolpath generation
3. CNC machining
4. Final assembly

This workflow supports precision, consistency, and compatibility with
robotic systems.

## Manufacturing Processes

Different components require different machining operations:

- Base Plate — facing, milling, and drilling
- Spur Gears — facing, gear cutting, and drilling
- Connecting Links — facing, milling, and drilling
- Gripper Fingers — facing, milling, drilling, and optional slotting
- Connecting Pin — turning, facing, and grooving
- Hinges — facing, milling, drilling, and possible bending

## CAPP Process Planning

The Computer-Aided Process Planning workflow consists of:

1. Requirement Analysis
2. Conceptual Design
3. Material Selection
4. CAD Modelling and Simulation
5. Motor Selection
6. Fabrication
7. Testing and Inspection

Each stage was assigned an equal weight of 14.3% in the overall
project process.

## Automation and ERP Integration

The gripper can be attached to a robotic arm for applications such as:

- Pick-and-place
- Assembly
- Inspection

The proposed automation workflow also considers the transmission of
real-time information such as errors, cycle time, and part count to
an ERP system for workflow optimization and resource management.

## Project Outcome

A two-finger mechanical robotic gripper was developed using a
gear-driven linkage mechanism and a single SG90 servo motor.

The design was validated using Fusion 360 motion studies and was
planned for fabrication using 3D printing and CNC machining.

The modular design provides scope for integration with robotic arms
and future intelligent automation systems.
